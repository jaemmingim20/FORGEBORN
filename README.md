# FORGEBORN — Phase 9 통합 빌드 (0.9.0)

[VS Code용 프로젝트 ZIP 다운로드](https://github.com/jaemmingim20/FORGEBORN/raw/refs/heads/main/releases/FORGEBORN-phase9.zip) · [로컬 실행 안내](START_HERE_KO.md)

중세 판타지 대장장이 시뮬레이터의 **Phase 3 — 제련과 광산 확장**입니다. 기존 이동·채굴·인벤토리를 유지하고, E 용광로 상호작용과 제련, 더 큰 분기형 광산을 추가했습니다. 공식 규칙은 [GDD.md](GDD.md), 제련 구현/제한은 [Phase 3 보고서](docs/PHASE3.md), 0.3.1 그래픽 변경과 검사 범위는 [그래픽 업데이트](docs/GRAPHICS.md)에 기록했습니다. Phase 4에서 다섯 종류의 무기 제작·가열·모루 미니게임·담금질·부품 구매·3D 조립을 추가했습니다. [Phase 4 실행 안내](docs/PHASE4.md)를 참고하세요. 손님·판매·전투·영구 저장은 이후 단계입니다.

[Phase 1 완료 보고서](docs/PHASE1.md)는 초기 구현 기록입니다. 이번 버전은 Phase 3 게임 규칙을 유지하면서 동굴·외관·재질·도구의 시각 표현과 나무 배치 문제를 개선합니다.

## 미리보기에서 바로 실행

### VS Code Go Live

프로젝트 ZIP을 풀고 `FORGEBORN` 폴더를 VS Code로 엽니다. Live Server 확장을 설치한 뒤 오른쪽 아래 **Go Live**를 누르세요. 프로젝트 설정이 `standalone/`을 서버 루트로 지정하므로 게임이 바로 열립니다. 이미 실행 중인 Live Server가 있으면 종료한 뒤 새 ZIP을 새 폴더에 풀어 여세요. 포함된 실행본은 npm 설치 없이 열 수 있습니다.

TypeScript 코드를 수정한 뒤에는 아래 빌드 명령으로 실행본을 갱신하세요. 개발 중 즉시 변경 반영은 `npm run dev`를 사용합니다.

```sh
npm run build
```

미리보기와 파일 공유용 실행본은 **`standalone/index.html`**입니다. 게임 코드, Three.js, Rapier WASM, 스타일, 한국어 글꼴을 약 8MB의 HTML 하나에 포함합니다. 추가 파일 다운로드가 필요하지 않습니다. 단일 실행본만 갱신하려면 `npm run build:standalone`을 사용합니다.

일반 웹 호스팅에는 `dist/` 전체를 배포합니다. 하위 경로에서도 에셋이 같은 폴더를 기준으로 로드되도록 상대 경로를 사용합니다. 저장소 루트의 `index.html`은 아래 Vite 개발 서버가 처리하는 소스 진입점입니다.

로딩 중에는 현재 준비 단계가 표시됩니다. 첫 스크립트·게임 모듈·WASM 로드가 실패하면 오류 안내와 재시도 버튼을 표시하고, 15초 이상 초기화가 지연되면 기다리거나 다시 시도할 수 있는 안내를 표시합니다.

## 실행

Node.js **22.12 이상**(개발 기준: 24.19.0), npm을 사용합니다.

```sh
cd FORGEBORN
npm ci
npm run dev
```

브라우저에서 Vite 서버를 열고 **대장간에 들어가기**를 누릅니다. PC의 키보드와 마우스, WebGL 2 및 WebAssembly가 필요합니다. 포인터 잠금은 사용자 클릭으로 시작합니다. iframe 안에서는 호스트가 `allow-pointer-lock`을 허용해야 합니다. 글꼴, 재질, 모델은 자체 번들/절차적 생성이며 런타임 CDN·백엔드·API 키가 필요 없습니다.

| 입력    | 현재 동작                                |
| ------- | ---------------------------------------- |
| W/A/S/D | 시점 기준 이동, 기본 4.5m/s              |
| 마우스  | 1인칭 시점 회전                          |
| Shift   | 달리기 6.5m/s                            |
| Space   | 지상에서 점프, 공중 연속 점프 금지       |
| G       | 현재 위치가 표시되는 탐방 지도 켜기/끄기 |
| 3       | 낡은 곡괭이 장착/해제                    |
| 좌클릭  | 바라본 광맥 채굴                         |
| E       | 가까이 바라본 용광로 열기                |
| Tab     | 인벤토리 열기/닫기                       |
| Esc     | 일시정지, 마우스 잠금 해제               |

일시정지 화면에서 감도와 걷기 카메라 움직임을 조절하고 시작 위치로 복귀할 수 있습니다. 창 포커스가 사라지거나 탭이 숨겨지면 멈춥니다. 설정과 방문 기록은 현재 세션에만 유지됩니다. G는 탐방 지도 키입니다. M(시장)과 J(일지)는 이후 단계용으로 남겨둡니다.

## 0.3.1 그래픽 변경

- **동굴 내부:** 평평한 상자 표면을 거친 퇴적층 암벽, 아치형의 울퉁불퉁한 천장, 가장자리 돌무더기와 바닥 요철로 덮습니다. 기존 분기·순환 통로와 광맥 접근 경로를 유지합니다.
- **광산 입구:** 큰 절벽 덩어리, 불규칙한 바위 아치와 두꺼운 목재 지지대로 갱도 외관의 규모감을 높입니다.
- **나무 겹침 수정:** 광산 전체 구획과 입구를 식생 금지 영역으로 예약합니다. 나무 중심점뿐 아니라 수관·뿌리의 전체 반경을 검사해 숲이 지하 통로나 입구를 침범하지 않게 합니다.
- **중세 대장간 외관:** 겹치는 지붕 타일, 박공 목조 골조, 석재 기단, 작은 지붕창, 창문 테두리와 굴뚝 연기를 추가합니다. 주변 숲과 먼 배경 건물의 실루엣도 개선합니다.
- **재질과 소품:** 목재 결, 암석 균열, 회벽·슬레이트·흙의 표면 요철/거칠기, 풍화된 금속을 절차적 PBR 재질로 표현합니다. 곡괭이는 휘어진 단조 머리·가죽 감은 나무 자루로, 방패 표적은 판재·철 테두리·보스·리벳으로 다듬습니다. 모루와 작업대·보관함에도 형상과 체결 디테일을 추가합니다.

이 업데이트는 시각 표현과 식생 배치 수정입니다. 이전 그래픽 업데이트의 기록입니다. 최신 Phase 4에는 아래 제작 흐름이 추가되었습니다.

## Phase 3 제련

철광석을 얻은 뒤 대장간의 돌 용광로를 바라보고 **E**를 누릅니다. `철 제련 시작`을 누르면 철광석 1개가 차감되고 게임 시간 12초 후 철 재료 1개가 인벤토리에 들어옵니다. 구리·은·미스릴도 대응 재료로 제련하고, 철 재료 1개 + 석탄 1개로 강철 재료를 만듭니다. 기본 제련에는 별도 연료가 필요하지 않습니다.

초기 용광로는 레벨 1, 1슬롯입니다. 상위 레벨의 여러 슬롯은 데이터/작업 구조로 지원하며 유료 업그레이드는 아직 없습니다. 인벤토리/제련창을 열어도 제련은 진행하고, Esc 일시정지에서는 멈춥니다. 완료 시 공간이 없으면 결과를 용광로에 보존합니다.

## 구현 범위

- 카운터 ↔ 대장간 ↔ 뒷마당 ↔ 훈련장, 뒷마당 ↔ 광산 입구의 연속된 월드
- Rapier 캡슐 캐릭터, 정적 충돌체, 고정 60Hz 물리, 중력·점프·낮은 턱 이동
- 용광로 1개, 모루, 담금질 수조, 조립 작업대, 재료 보관함, 완성품 보관대, 구매 장부, 침대
- 응대 카운터, 빈 손님 대기 공간, 완성품 제출대, 운반 수레
- 허수아비 3개, 방패 표적, 훈련 기록판
- 목조/석조 대장간, 숲·산 실루엣·흙길·돌길·울타리, 그림자, 금속 재질, 용광로/횃불 발광과 조명
- 광맥 좌클릭 채굴·수집, Tab 인벤토리, E 용광로 제련을 실제 시스템에 연결
- 모루·조립 작업대·판매 카운터 등 후속 단계 설비는 용도 안내만 제공

광산은 약 750m의 전방 영역으로 확장했습니다. 266개 구획, 5개 대형 공동(각 30×30m), 분기점 56개, 독립적인 순환 경로 32개, 막다른 지점 8개가 연결됩니다. 전체 통로 연결 길이는 약 2.97km, 통로 기준 최심부 거리는 약 1,015m입니다. 광물 깊이 조건과 기본 타격 횟수는 유지합니다.

G로 주변 지하 지도를 열 수 있습니다. HUD의 출구 방향은 실제 통로를 따라 입구로 돌아가는 최단 경로를 가리킵니다. 깊이는 통로 그래프 기반 근사 거리입니다. 시작 곡괭이로 구리/철/석탄을 채굴하며, 은과 미스릴은 이후 상위 장비가 필요합니다. 첫 철광석은 여전히 입구 약 7m 안쪽 왼쪽 벽에 있습니다.

진행 상태는 현재 세션에만 유지됩니다. 날짜·광맥 재생성·영구 저장은 아직 없습니다.

## 검사

```sh
npm run typecheck
npm test
npm run build
npm run test:browser
```

`test:browser`는 실제 Chromium에서 개발 서버 및 빌드한 정적 결과물을 검사합니다. `/usr/bin/chromium`이 있으면 사용하고, 다른 머신은 `npx playwright install chromium`으로 설치하거나 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 경로를 지정합니다. Linux에서 라이브러리가 부족하면 Playwright 공식 설치 안내에 따라 브라우저 런타임 의존성을 준비합니다. 테스트는 1개 워커와 소프트웨어 WebGL로 실행하며, 브라우저 탐방 테스트는 수 분 걸릴 수 있습니다.

실패 시 `test-results/`에 스크린샷과 trace를 남깁니다. 정상 실행 스크린샷도 이 디렉터리에 생성합니다. 테스트 전용 `?debug` 훅은 Vite 개발 모드에서만 동작하며 프로덕션 번들에는 노출되지 않습니다. 구역 왕복 검사는 순간이동 없이 실제 키 입력으로 진행합니다. 설비 충돌 검사에만 개발용 위치 지정 훅을 사용합니다.

## 구조와 확장

[구현 전 구조 설계](docs/ARCHITECTURE.md)에 파일 구조, 모듈 경계, 좌표와 기본값을 기록했습니다. `src/world/data.ts`는 구역/설비의 데이터이며, `ModelFactory`는 설비 외형, `WorldBuilder`는 배치와 충돌체, `WorldManager`는 구역/시선 판별을 담당합니다. 게임 규칙은 렌더러에 두지 않습니다. 최신 제작 시스템은 `CraftingManager`와 `CraftingUI`, `WeaponModel`에 있으며 다음 개발은 **Phase 5 손님 및 경제**입니다. 채굴 규칙과 인벤토리는 렌더러와 분리된 `MiningManager`, `InventoryManager`에 둡니다.

Rapier 호환 패키지는 WASM을 포함하므로 물리 청크가 비교적 큽니다. 첫 로드는 네트워크/기기에 따라 오래 걸릴 수 있으며 로딩 화면을 제공합니다. 모델과 재질은 교체 가능한 절차적 생성 방식입니다. 실제 GPU별 성능 최적화와 사운드는 후속 개선 대상입니다. 참고 이미지의 분위기·재질·형상을 디자인 방향으로 사용했고, 워터마크가 있는 이미지 자체를 게임 텍스처나 모델로 포함하지 않았습니다.

관련 핵심 검사는 `npm run typecheck`, `npm test -- tests/cave-geometry.test.ts tests/vegetation.test.ts`, `npm run build`입니다. 채굴·제련 동작 확인에는 `npm run test:phase3`를 사용할 수 있습니다. 이번 그래픽 작업의 검사 범위와 결과 기록은 [GRAPHICS.md](docs/GRAPHICS.md)를 따릅니다.

## Phase 4 제작하기

조립 작업대 E에서 장비와 금속 수량을 선택한 뒤 **용광로 E → 모루 E → 담금질 수조 E → 조립 작업대 E** 순서로 진행하세요. 완성품은 보관대 E 또는 Tab 인벤토리의 제작 기록 버튼에서 3D로 확인합니다. 기본형 부품은 무료이며 초기 자금은 200동화입니다. 자세한 조작과 범위는 [Phase 4 안내](docs/PHASE4.md)에 있습니다.

이번 Phase 4는 요청에 따라 테스트·타입 검사·브라우저 점검을 생략하고 배포 빌드만 생성했습니다. 이전 보고서의 검사 결과는 이전 버전에 대한 기록입니다.

## 최신 Phase 5–9 통합

손님 주문·판매·시장·분해, 제작 장비 장착·공격·방어, 광산 몬스터, 용광로 성장·날짜·정산·저장, 구획별 광산 표시를 추가했습니다. 최신 기능·조작·제한은 [Phase 5–9 안내](docs/PHASE5-9.md)를 참고하세요. 위의 이전 페이즈 설명과 보고서는 각 단계 당시 기록입니다.

카운터 E 주문 / 침대 E 다음 날 / 1 주 무기 / 2 방패 해제 / 3 채굴 / 우클릭 방어 / M 시장 / J 기록·저장. 요청에 따라 이번 버전은 테스트·타입 검사·실행 점검 없이 Vite 빌드만 생성한 미검증 빌드입니다. GPU 성능을 확인했다는 뜻은 아닙니다.
