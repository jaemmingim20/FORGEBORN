# FORGEBORN 0.3.1 — 동굴과 중세 환경 그래픽 업데이트

이 버전은 Phase 3 게임의 그래픽 개선과 광산 내부에 식생이 겹치는 버그 수정이다. 공식 게임 규칙은 `GDD.md`, 제련과 광산 그래프의 기반은 `PHASE3.md`를 따른다. 채굴·제련·인벤토리·이동을 유지하며 무기 제작·판매·전투를 새로 구현하지 않는다.

## 참고 이미지 반영 범위

사용자가 제공한 이미지는 목조 골조와 회벽, 석재 기단, 겹쳐진 지붕, 풍화된 철과 나무 자루 등의 재질·형상 방향을 참고하는 데 사용한다. 이번 모델과 표면 맵은 코드로 절차적으로 생성하며, 참고 이미지 자체를 텍스처로 사용하지 않는다.

## 동굴 내부

- 상자형 구획의 평평한 노출 면을 좌표 기반 요철이 있는 암벽으로 교체한다. 층리와 균열을 가진 재질을 함께 사용한다.
- 천장은 낮은 가장자리와 높은 중심부를 가진 불규칙한 아치형 표면으로 만든다. 연결 구획 사이를 겹쳐 평평한 격자 이음새가 드러나는 것을 줄인다.
- 통로 가장자리의 바위, 돌무더기, 천장 돌기와 약한 바닥 기복을 추가한다. 레일과 중앙 보행 경로는 평평하게 유지한다.
- 기존 광산 그래프, 입구, 광맥 ID와 접근 위치를 유지한다. 통로 연결부와 플레이어 높이의 통행 여유를 보존하고, 광석을 시각적 암벽 뒤로 감추지 않도록 표면 범위를 제한한다.

관련 파일: `src/world/MineBuilder.ts`, `src/world/caveGeometry.ts`.

## 웅장한 입구와 대장간 외관

광산 입구를 큰 절벽 덩어리와 불규칙한 암석 아치로 감싸고 목재 지지·버팀 구조를 더한다. 기존의 걸어 들어가는 통로와 초반 철광석 위치는 유지한다.

대장간은 겹치는 슬레이트 지붕 타일, 박공·대각 목조 골조, 석재 기단, 지붕창과 창문 테두리를 추가한다. 굴뚝 연기, 먼 배경의 중세풍 집, 더 다양한 수관과 능선으로 외관의 규모와 생활감을 보완한다. 배경 건물은 장식이며 손님·상점 등 새 게임 시스템은 아니다.

관련 파일: `src/world/WorldBuilder.ts`, `src/world/ExteriorDecor.ts`, `src/world/WorldManager.ts`.

## 광산 내부 나무 겹침 수정

이전의 숲 배치는 지상 기준의 반경과 나무 중심점만으로 배치 가능 여부를 판단해, 북쪽으로 뻗은 광산과 가지 통로 위에 수관이나 뿌리가 겹칠 수 있었다.

`vegetation.ts`에서 전체 광산 구획과 입구·접근부를 식생 금지 영역으로 예약한다. 암벽 두께를 포함한 여유 영역과 나무의 전체 수관/뿌리 반경을 검사한다. 이 규칙을 나무뿐 아니라 풀·주변 큰 바위 등의 배치에도 적용한다. 나무를 숨기는 임시 화면 처리 대신 생성 위치에서 겹침을 막는다.

관련 파일: `src/world/vegetation.ts`, `tests/vegetation.test.ts`.

## 재질·조명·소품

- 목재 결·균열, 암석의 입자와 풍화 흔적, 회벽의 얼룩, 슬레이트 이음, 흙·풀의 색 변화, 금속 표면의 마모를 색상·노멀·거칠기 맵으로 생성한다. 실행 중 외부 이미지 다운로드는 사용하지 않는다.
- 금속이 균일한 검정이나 흰색으로 보이지 않도록 조명과 반사 환경을 보완하고, 지하에서는 낮은 채도의 암석과 따뜻한 작업 조명이 읽히도록 조절한다.
- 곡괭이는 굽은 단조 철 머리, 완만하게 휜 나무 자루, 감긴 그립, 고정 소켓과 리벳으로 다듬는다. 기존 장착·채굴 애니메이션에 연결한다.
- 훈련용 방패 표적은 판재, 철 테두리, 중앙 보스와 리벳을 갖춘다. 모루는 잘록한 몸통과 뿔을, 작업대·보관함은 판재 간격·못·철물 디테일을 갖춘다.
- 소품의 기존 ID와 충돌 명세는 유지한다. 실제 무기 제작이나 방패 전투 판정을 추가한 것은 아니다.

관련 파일: `src/render/surfaceTextures.ts`, `src/render/materials.ts`, `src/render/SceneRenderer.ts`, `src/world/ModelFactory.ts`, `src/world/PickaxeModel.ts`, `src/mining/MiningView.ts`.

## 실행과 전달

[그래픽 업데이트 ZIP](https://github.com/jaemmingim20/FORGEBORN/raw/refs/heads/main/releases/FORGEBORN-phase3-graphics.zip)을 새 폴더에 풀고 VS Code에서 `FORGEBORN` 폴더를 연다. 기존 Live Server를 종료한 뒤 **Go Live**를 누른다. `.vscode/settings.json`이 `standalone/`을 서버 루트로 지정한다.

`standalone/index.html`은 코드·글꼴·재질·모델 생성을 포함하는 약 8MB의 단일 HTML 실행본이다. 소스 수정 시 `npm run build:standalone`, 일반 배포와 실행본을 함께 만들 때는 `npm run build`를 사용한다. Vite 개발 실행은 `npm ci` 후 `npm run dev`다.

## 검사 명령과 범위

아래는 이 변경에 관련된 검사 명령이다.

```sh
npm run typecheck
npm test
npm run build
npm run format:check
```

확인 대상:

- 암벽 표면이 광맥과 보행 여유 범위를 침범하지 않는지.
- 동굴 구획과 입구 예약 영역을 나무 전체 반경이 침범하지 않는지.
- 짧은 이동으로 입구를 지나고 기존 채굴/제련 상호작용으로 복귀할 수 있는지.
- 시작 화면, 입구 외관, 대장간, 동굴 내부와 곡괭이가 브라우저에서 의도대로 보이는지.
- Go Live용 실행본에서 에셋 로드 오류가 없는지.

전체 광산 장거리 도보, 모든 통로의 수동 순회, GPU별 성능 비교는 이 그래픽 수정의 기본 검사 범위에 포함하지 않는다. 영구 저장과 날짜, 상위 장비 제작, 전투는 여전히 후속 단계다.

- Chromium에서 첫 철광석을 실제 좌클릭 3회로 수집하고 입구를 걸어서 통과했다. E 용광로 열기, 광석 차감, 제련 완료와 인벤토리의 철 재료도 확인했다. 완료 시간 검사는 개발 전용 시간 진행 훅을 사용했다.
- 보정한 입구와 동굴 화면을 캡처해 상단 암반 연결, 겹친 표지 제거, 잔디 노출 방지와 새 재질을 확인했다.
- 빌드된 단일 HTML을 별도로 제공해 시작·마우스 잠금·인벤토리·곡괭이 표시를 확인했다. 프로덕션의 개발 전용 훅은 없으며, 브라우저 오류는 없었다.
- 브라우저 검사는 소프트웨어 WebGL 환경에서 진행했다. 실제 GPU의 프레임 속도를 측정한 결과는 아니다.
