## 알려진 제한

- 모델은 절차적으로 생성한 교체 가능한 임시 모델이다. 최종 아트·애니메이션·사운드·세부 그래픽 최적화는 후속 단계 대상이다.
- Rapier 호환 패키지가 WASM을 포함하여 물리 청크는 약 4.33MB, gzip 약 1.67MB다. 빌드 시 크기 경고가 발생한다. 초기 로딩은 네트워크와 기기에 따라 오래 걸릴 수 있으며 로딩 화면을 제공한다.
- 검증은 Chromium의 소프트웨어 WebGL에서 수행했다. Firefox/Safari 및 실제 GPU별 성능은 미검증이다.
- 광산은 짧은 입구 구간까지만 접근할 수 있다. 채굴 가능한 광맥이나 500m 광산 내부는 없다.
- 인벤토리·곡괭이 장착·채굴·제련·제작·손님·거래·화폐·전투·체력/스태미나·날짜·저장은 아직 동작하지 않는다. 방문 기록과 조작 설정은 현재 세션에만 유지된다.

## 다음 개발 단계

**Phase 2 — 채굴 시스템**만 다음으로 진행한다.

1. 고정 시드 광산 내부 생성 및 구역/깊이 데이터.
2. 기획서의 깊이·안전 구역 규칙에 맞는 광물 배치.
3. 낡은 곡괭이 장착, 1인칭 뷰모델과 채굴 애니메이션.
4. 광맥 타격·고갈·중복 수집 방지, 광물 수집.
5. 채굴에 필요한 인벤토리 모듈과 UI 연결.
6. 철광석을 채굴해 대장간으로 돌아오는 기능 검증과 Phase 1 이동 회귀 검사.

제련은 Phase 3, 제작은 Phase 4, 경제는 Phase 5에 구현한다.

## 재사용 환경 설정

환경 설정 초안의 `install_script`에 잠금파일 재설치·타입 검사·테스트·빌드를 저장했다. `start_skill`에는 기존 체크아웃 사용, 별도 worktree를 만들지 않는 지침, Vite 시작 경로와 명령, 실행 확인 방법, 브라우저 테스트와 Phase 1 범위를 저장했다. 실제 설치 스크립트도 현재 머신에서 실행해 확인했다. 비밀값이나 추가 네트워크 도메인은 필요하지 않았다.

초안 저장은 확인했으나 환경 게시는 수행하지 않았다. 새 작업에서의 스냅샷 복원도 검증하지 않았다. 필요한 경우 환경 설정에서 내용을 검토·저장한 뒤 게시한다. 프로세스와 마우스 잠금은 새 작업에서 다시 시작해야 한다.

## 미리보기 로딩 고정 수정

하위 경로에 정적 빌드를 올리고 사이트 루트의 `/assets/`를 제공하지 않는 조건에서, 게임 파일이 404가 되어 `F / 대장간의 불을 지피는 중…`만 남는 증상을 재현했다. 처음의 개발 서버·루트 경로 테스트에는 이 조건이 빠져 있었다.

수정 범위:

- Vite의 `base`를 `./`로 설정해 빌드 파일의 에셋 주소를 상대 경로로 생성한다.
- `standalone/index.html`에 게임 코드·Three.js·Rapier WASM·스타일·한국어 글꼴을 포함한다. 약 7.70MB, gzip 약 3.91MB다. 일반 웹 배포용 `dist/`는 청크 분리를 유지한다.
- `main.ts`에서 `startGame.ts`를 오류 경계 안으로 동적 로드해 게임 모듈 다운로드 실패도 처리한다.
- HTML 자체의 안내와 오류 처리는 첫 모듈/CSS보다 먼저 실행된다. 프로덕션 HTML 재작성 후에도 오류 안내가 유지된다.
- 초기화 단계를 표시하고 15초 지연 시 안내·재시도를 제공한다. 느린 정상 초기화는 이후 완료될 수 있다.
- WOFF2 글꼴 3개만 번들에 포함한다. 이동·월드·기획서 규칙에는 변경이 없다.

추가 브라우저 회귀 검사 7개가 통과했다:

1. `/nested/forgeborn/` 하위 경로에서 로딩·시작 및 에셋 요청 성공.
2. HTML 파일 하나만 제공하는 서버에서 추가 HTTP 요청 없이 로딩·대장간→뒷마당 이동·일시정지 성공.
3. 개발 모드의 첫 스크립트 차단 시 안내·재시도 표시.
4. 프로덕션의 첫 스크립트 차단 시 HTML에서 안내·재시도 표시.
5. 게임 모듈 실패 안내 후 재시도로 정상 복구.
6. WASM 초기화 실패 안내.
7. 완료되지 않는 초기화의 15초 지연 안내.

이 검증은 Chromium과 HTTP 기반 미리보기 조건에서 수행했다. 사용자의 원래 미리보기 주소 자체에 직접 접속해 검증한 것은 아니다. 재생성된 단일 HTML 실행본은 `standalone/index.html`이다.
