# Phase 3 — 제련과 광산 확장

## 구현 전 설계

공식 GDD Phase 3 범위: 용광로 상호작용, 광석 선택과 차감, 제련 진행, 완료 재료 생성, 다중 슬롯 구조. 초기 용광로는 기획서대로 1개·레벨 1·1슬롯·12초를 유지한다. 상위 레벨의 2~5슬롯은 데이터와 독립 작업 구조로 지원하고 유료 증설/업그레이드는 Phase 8에 남긴다. 철광석 1→철 재료 1, 철 재료 1+석탄 1→강철 재료 1이다. 기본 제련에 별도 연료는 필요하지 않다.

- `src/items/data.ts`: 광석과 제련 재료의 공통 아이템 정의.
- `InventoryManager`: 일반 아이템 카운트 및 원자적 재료 교환.
- `src/smelting/SmeltingManager.ts`: 설비별 슬롯/레벨, 입력 예약, 시간 진행, 완료/공간 대기.
- `src/ui/SmeltingUI.ts`: E로 여는 제련 패널과 실제 재료·슬롯·진행 표시.
- `src/world/mineLayout.ts`: 고정 시드 격자 그래프와 입구 기준 통로 거리.
- `MineBuilder`, `mining/data.ts`: 같은 그래프를 사용해 벽 없는 연결부, 외곽 충돌체와 접근 가능한 광맥 생성.

사용자의 광산 확장 요청에 따라 주 진행 방향을 500m에서 약 750m로 늘리고 횡방향 분기, 막다른 채굴실, 우회로와 큰 공동을 추가한다. 광물 최소 깊이 100m/250m와 기존 광산 5구역 경계는 유지한다. 깊이는 Z 좌표가 아니라 입구에서 연결된 통로를 따라가는 최단 진행 거리다. 출구 방향 표지와 지하용 지도를 제공한다.

인벤토리/제련창에서는 이동을 멈추되 제련 시간은 진행한다. Esc 일시정지와 시작 화면에서는 멈춘다. 완료 시 공간이 없으면 결과를 작업 슬롯에 보존하고, 재료나 결과를 복제/손실시키지 않는다. 영구 저장·날짜·전투·제작·경제는 구현하지 않는다.

검증은 타입, 짧은 핵심 제련/맵 연결 테스트, 빌드와 짧은 상호작용 확인만 수행한다. 전체 광산 도보와 긴 회귀 검사는 생략한다.

## 완료 결과

- 용광로 E 상호작용, 광석/합금 선택, 입력 즉시 차감, 진행률과 남은 시간, 자동 재료 수집.
- 초기 레벨 1 용광로 1개·1슬롯·12초. 레벨별 12/9/7/5/3초 및 1~5슬롯 데이터, 설비별 독립 작업.
- 구리/철/은/미스릴 광석 1개 → 해당 재료 1개. 철 재료 1 + 석탄 1 → 강철 재료 1.
- 재료/빈 슬롯 부족 처리, 원자적 교환, 결과 중복 지급 방지. 완료 시 가방이 가득 차면 작업에 보관하고 공간 확보 후 수집한다.
- 인벤토리에 광석과 제련 재료를 모두 표시. 창을 열어둔 동안에도 제련은 계속되고 게임 일시정지 중에는 멈춘다.
- 광산 266개 구획(바닥 약 26,600m²), 전방 영역 약 750m, 횡방향 약 220m, 전체 연결 길이 약 2.97km.
- 대형 공동 5개(각 30×30m), 분기점 56개, 순환 경로 32개, 막다른 지점 8개. 입구 기준 최심부 통로 거리는 약 1,015m.
- 외곽 벽을 따라 광맥을 재배치하고, 깊이 조건은 유지했다. 처음의 입구 7m 철광석도 유지한다.
- 주변 지하 지도와 실제 귀환 경로를 가리키는 방향 안내. 깊이는 격자 통로 그래프 기반 근사 진행 거리다.
- 깊은 갱도의 최소 조명을 보완했고, 지상 외곽은 막아 빈 공간으로 나가지 않게 했다.

## 파일과 경계

추가: `src/items/data.ts`, `src/smelting/SmeltingManager.ts`, `src/ui/SmeltingUI.ts`, `src/ui/smelting.css`, `src/world/mineLayout.ts`, `tests/smelting.test.ts`, `tests/mine-layout.test.ts`, `tests/phase3.spec.ts`.

기존 연결 수정: 공통 게임 상태/이벤트, 게임 매니저, E 입력, 인벤토리의 일반 아이템과 원자적 교환, 광맥 생성, 광산 모델, 구역 범위, HUD/지하 지도, 조명. 기존 끝 벽 검사는 확대된 최종 구획을 참조하도록 갱신했으며 해당 긴 검사는 실행하지 않았다.

## 검증 결과

- 타입 검사와 일반/단일 HTML 빌드 통과.
- 핵심 테스트 36개 통과(기존 27 + 제련 6 + 광산 그래프 3). 실행 시간 약 0.7초.
- 짧은 브라우저 확인 2개 통과(약 34초). E 상호작용, 실제 입력 차감/진행 표시, 철·강철 출력, 인벤토리 재료 표시, 분기 통과, 지하 지도, Go Live용 실행본 초기화를 확인했다.
- 브라우저 확인의 재료와 제련 시간은 개발 전용 훅으로 주입/진행했다. 실제 창을 연 채 시간 감소도 확인했으며, 긴 12초 반복 대기와 전체 도보 회귀를 피했다.
- 깊은 갱도 조명을 보완한 뒤 짧은 화면 확인에서 실행 오류가 없고 통로가 보이는 것을 확인했다.
- 전체 광산 도보, 전체 브라우저 회귀, 실제 GPU별 성능 검증은 요청에 따라 생략했다.
- 기존 Rapier WASM 청크의 빌드 크기 경고는 유지된다.

## 미구현과 다음 단계

영구 저장/날짜, 설비 유료 증설/업그레이드 UI, 상위 곡괭이 제작, 전투, 판매는 이번 범위가 아니다. 현재 작업과 아이템은 새로고침하면 초기화된다. 다음 단계는 Phase 4의 모루·담금질·부품 조립과 무기 제작이다.
