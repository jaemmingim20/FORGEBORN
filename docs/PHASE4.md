# Phase 4 — 무기 제작 (0.4.0)

GDD의 Phase 4 범위인 다섯 장비 제작을 구현했다. 이전 그래픽 업데이트와 광산·채굴·제련을 포함한다.

## 제작 방법

1. 광산에서 광석을 채굴하고 용광로에서 금속 재료로 제련한다.
2. 조립 작업대 가까이에서 E를 눌러 검·방패·망치·도끼·곡괭이 중 하나를 선택한다. 금속은 각각 3·4·5·4·3개 필요하며 혼합 가능하다. 수량을 입력하고 제작을 시작하면 금속을 차감한다.
3. 용광로로 이동해 E를 누른다. 가열 게이지 65–80% 부근에서 추출한다.
4. 모루에서 E를 누른다. 금속 가공판의 원 중심을 여섯 번 클릭한다. 원 위치가 매번 바뀌며 클릭 정확도가 품질에 반영된다.
5. 담금질 수조에서 E를 누른다. 냉각을 시작하고 1.8–2.8초에 물에서 꺼낸다.
6. 조립 작업대에서 E를 눌러 세 부품의 등급을 각각 선택하고 구매·조립한다.
7. 완성품의 회전하는 3D 모델과 고유 번호, 금속 구성, 부품, 품질, 공격력/방패 감소율, 최대 내구도, 기준 가치를 확인한다.

완성품 보관대의 E 또는 Tab 인벤토리의 **완성 장비 · 3D 제작 기록 보기**에서도 완성품을 선택할 수 있다. 최대 20개의 고유 완성품을 별도 보관한다. 창은 닫기·Tab·Esc로 닫는다.

## 규칙

- 초기 자금 200동화. 기본형 부품은 무료·무제한이며 일반형 50, 고급형 150, 명품형 350동화다. 각 부품은 독립 선택하며 완성 시 합산 비용을 차감한다. 잔액 부족 시 작업을 유지하고 무료 부품으로 변경할 수 있다.
- 금속 부족 또는 잘못된 수량이면 시작하지 않는다. 진행 중 작업은 하나이며 창을 닫아도 금속과 단계는 현재 세션에 보존한다. 가열과 냉각 시간은 해당 설비의 제작창에서만 진행하며 일시정지하거나 이동하는 동안 멈춘다.
- 가열 정확도 25점 + 모루 여섯 타격 평균 50점 + 냉각 시간 정확도 25점으로 0–100점 품질을 생성한다. 잘못 가공해도 재료 전체가 사라지지 않고 낮은 품질로 완성할 수 있다.
- 품질 구간은 조잡함 0–39, 보통 40–69, 우수 70–89, 걸작 90–100이다.
- 성능은 GDD의 기본 성능 × 혼합 금속의 평균 계수 × (0.8 + 품질 × 0.004)를 반올림한다. 방패는 같은 계수로 감소율 수치를 생성한다. 초기 내구도 기준은 100에 같은 계수를 적용한다.
- 가치는 금속 기준 가치의 합과 부품 구매가의 합이다. 품질에 따른 가격 보너스는 없다.
- 3D 모델은 금속 혼합 색과 부품 등급을 반영한 모듈식 절차적 지오메트리다. 모든 완성품은 독립된 제작 데이터를 가진다.

## 범위 및 전달

판매와 손님·수입은 Phase 5, 실제 장착·공격·방어와 내구도 소모는 이후 장비/전투 단계다. 이번에는 제작 결과의 성능·내구도 데이터를 생성한다. 진행은 현재 세션 전용이며 새로고침 시 초기화된다.

사용자 요청에 따라 테스트, 타입 검사, 브라우저 실행 및 플레이 점검은 수행하지 않았다. 배포용 Vite 빌드만 수행한다. 런타임 정상 작동을 검증했다는 의미는 아니다.

`releases/FORGEBORN-phase4.zip`에는 소스, 공식 GDD, Go Live 설정, 단일 HTML 실행본, 설명과 서드파티 라이선스를 포함한다. 새 폴더에 풀어 VS Code에서 FORGEBORN 폴더를 열고 Go Live를 누른다.
