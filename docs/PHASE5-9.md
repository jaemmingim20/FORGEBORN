# Phase 5–9 통합 구현 — 0.9.0

Phase 4의 제작과 기존 동굴 그래픽을 유지하고 운영·전투·성장 시스템을 연결했다. 사용자 요청으로 테스트, 타입 검사, 브라우저 실행 및 플레이 점검은 생략했다. Vite 배포 빌드는 실행본 생성용이며, 플레이 정상 동작이나 GPU 성능을 검증한 결과는 아니다.

## 플레이 흐름

카운터 E로 손님 주문 확인 → 광산에서 채굴 → 용광로 제련 → 작업대에서 제작 시작 → 용광로 가열 → 모루 → 수조 → 작업대 조립 → 카운터 E에서 무기 제출·제안 수락/거절. Tab의 장비 관리 버튼으로 장착하고 1로 주 무기, 3으로 채굴 도구를 선택한다. M은 시장, J는 기록·저장이다. 침대 E로 다음 날을 시작한다.

## Phase 5 손님·경제

- 카운터 앞 3D 손님. 주문은 다섯 장비 각각 20%, 특수 손님 8%. 한 번에 한 명, 하루 처리 최대 5명.
- 일반 ±30%, 특수 ±60%의 변동률을 손님 생성 시 확정하며 무기 제출 시 가격을 한 번만 확정한다. 주문과 다른 장비 제출은 거부한다.
- 수락은 장비 삭제와 입금, 거절은 장비 보존과 손님 퇴장으로 연결된다. 처리 후 다음 손님을 생성한다. 제출한 장비는 시장 판매·분해를 막는다.
- M 시장에서 장비 선택 후 확인하면 기준 가치의 90%를 정수 내림해 지급한다. 시장 판매는 손님 제한과 독립이다.
- 작업대의 장비 관리·분해에서 금속 종류별 투입량의 70%를 정수 내림하여 반환한다. 공간 부족이면 분해하지 않는다. 부품은 회수하지 않는다.

## Phase 6 전투·훈련

- 주 무기·방패·채굴 도구 고유 ID 장착. 1 주 무기, 2 방패 해제, 3 곡괭이 선택. 우클릭 유지로 정면 방어한다.
- 1인칭 모듈 장비 모델과 공격 애니메이션. 타격 시점 0.22초에 사거리·방향·벽 가림을 반영해 피해를 준다. 검·도끼·망치 대기시간은 0.55·0.85·1.2초다.
- 체력/스태미나 100, 공격·채굴·달리기·방어 소모와 회복. 안전한 광산 150m 이전 구간과 지상에서 체력을 회복한다.
- 훈련장 허수아비와 방패 표적에 타격 피해량을 표시한다. 유효 타격/채굴/방어 시 장비 내구도가 줄며 0이면 사용할 수 없다.
- 철 이상 제작 곡괭이는 은, 강철 또는 미스릴이 포함된 곡괭이는 미스릴 채굴이 가능하다. GDD에 상세 채굴 등급 판정이 없어 이 규칙을 기본값으로 사용한다.

## Phase 7 광산 몬스터

- 동굴 쥐 150m 이후(체력30/공격6), 고블린 250m 이후(65/12), 골렘 375m 이후(180/25).
- 18m 이상 떨어진 카메라 뒤쪽 통로에서 생성, 주변 활성 최대 5마리. 깊이에 따라 생성 간격이 짧아진다. 같은 날 같은 구획의 중복 생성은 제한한다.
- Idle/Patrol/Chase/Attack/Return/Defeated 상태, 광산 연결 그래프 경로 탐색과 이동 전 암벽 충돌 레이를 사용한다. 안전 구역을 추적하지 않는다.
- 제작 무기 성능으로 피해, 방패 정면 피해 감소와 기력/내구도 소모, 소량 동화와 낮은 확률 광석 보상.
- 사망하면 소지 광물의 종류별 20%를 내림하여 잃고 입구로 복귀한다. 장비와 완성품은 유지한다.

## Phase 8 성장·저장

- 용광로 강화 비용 800/2000/4500/10000동화, 레벨별 12/9/7/5/3초와 1/2/3/4/5슬롯. 현재 작업은 시작 당시 시간을 유지한다.
- 증설 비용 1500/4000/9000동화, 최대 네 개. 증설 모델·충돌체를 생성하며 각 용광로가 별도 작업 큐를 갖는다. 기존 용광로 창의 관리 버튼에서 모든 큐를 조작할 수 있다.
- 침대에서 날짜 변경, 매출·시장 수입·부품/강화 비용·순현금·제작·채굴·최심부 정산. 최근 30일 기록을 저장한다. 날짜마다 고갈 광맥의 약 1/3을 결정적으로 재생하며 몬스터를 갱신한다.
- 5초 간격 및 창 닫힘/페이지 숨김 시 localStorage 자동 저장, 시작 시 자동 불러오기, J의 수동 저장/불러오기. 직전 저장은 백업 키로 남긴다.
- 광석·재료, 완성품과 제작 중 작업, 잔액, 날짜·손님·제안 금액·일일 기록, 용광로 큐, 광맥 상태, 장비 슬롯·내구도·체력, 몬스터 상태와 위치를 포함한다.
- 저장은 브라우저와 사이트 주소별이다. 다른 브라우저, 포트 변경, 저장소 삭제 시 자동 공유되지 않는다. 저장소 접근 실패 시 화면에 안내한다.

## Phase 9 시각·최적화

- 이전 그래픽 업데이트의 거친 동굴, 절벽 입구, 절차적 색상/노멀/거칠기 텍스처와 금속 반사, 목조 건물과 도구를 포함한다.
- 손님과 몬스터 교체 가능한 절차적 모델, 장비별 1인칭 모델, 타격 파티클, Web Audio 효과음, 체력·기력·날짜·화폐·장비 HUD와 관리 UI.
- 광산을 구획별 정적 배치로 분리하고 플레이어 주변 70m 이내 구획을 활성화한다. 원거리 몬스터와 광맥 표시를 제한한다. CPU 형상과 물리는 메모리에 유지하고, 비활성화하는 구획의 GPU 지오메트리 버퍼를 해제한다. 재진입 시 Three.js가 버퍼를 다시 업로드하는 방식이다.
- 실제 GPU 성능, 장거리 통로 이동, AI 전투 균형과 저장 복구의 실행 검증은 수행하지 않았다. 이 버전은 Phase 5–9 코드를 통합한 미검증 빌드다.
